# 🤖 Портфолио автоматизации бизнеса

Автоматизирую рутинные бизнес-процессы с помощью n8n.  
Специализация: интеграция CRM, seo-маркетинг, яндекс-директ-автоматизации, AI-агенты.

## 👨‍💼 Для кого
Бизнесмены и предприниматели, которые хотят:
- Сэкономить время на рутинных задачах,
- Автоматизировать интеграции между системами,
- Получать автоматические отчеты и уведомления.

## 📊 Кейсы

### [Поиск битых ссылок](workflows/404-links/)
Проверка ссылок в файле exel через Телеграм-бота на 404-ответ. Удобно для всех директологов и SEO
**Результат:** 10+ часов/месяц экономии

### [Проверка статуса товаров на сайте завода ELTEX по API](workflows/eltex_co/)
Для всех дилеров продукции ELTEX, которые следят за статусом и наличием товаров у завода-производителя.
**Результат:** 20+ часов/месяц экономии

### [Логирование переписок в Telegram](workflows/telegram_logs/)
Автоматическое логирование **ВСЕХ** сообщений Telegram-бота в Supabase + FTP. Фиксирует текст, фото, видео, голосовые в момент отправки и получения.
**Результат:** Информационная безопасность, доказуемость ваших договоренностей.

### [Автоматическая ежедневная проверка баланса AI по API](workflows/balance_ai/)
Автоматический мониторинг баланса и расходов OpenAI, DeepSeek, Replicate.
**Результат:** Своевременное пополнение аккаунтов ai, избегание ситуаций остановки в работе.

### [Интеграция Bitrix24 + аналитика лидов](workflows/bitrix-integration/)
Система проверки классификации лидов в СРМ Bitrix24. Каждая компания имеет свои отличия в ведении и особенностях строения системы. Покажу общие принципы, без деталей конкретной CRM.
*(готовится к публикации)*
